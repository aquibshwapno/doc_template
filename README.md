# Shwapno Document & Deck Templates

Brand templates for ACI Logistics (Shwapno) deliverables, used with Claude to
produce on-brand documents and slide decks without re-uploading the template
each time.

## Files

- **Shwapno_Doc_Template.docx** — Word template: Times New Roman body,
  bold/underlined section headings, shaded-header tables, running header, ACI
  logo footer, cover page, and a process-flowchart example.
- **Shwapno_Deck_Template.pptx** — PowerPoint template: 16 real slide layouts on
  the red/black Shwapno brand (cover, section divider, FY roadmap matrix,
  timeline, task grid, icon-card grid, product overview, feature list, icon
  flowchart, swimlane flowchart, user-flow, competitor matrix, concept, list,
  chart).

## Raw links

- Doc:  https://raw.githubusercontent.com/aquibshwapno/doc_template/main/Shwapno_Doc_Template.docx
- Deck: https://raw.githubusercontent.com/aquibshwapno/doc_template/main/Shwapno_Deck_Template.pptx

## Usage

The instruction that makes Claude use these lives in the Claude Project settings,
not here. To update a template, replace the file in this repo with the same file
name — the raw link stays current automatically.
